Integrasi Supabase Cloud

Memeriksa koneksi...

Hubungkan aplikasi ke database Supabase agar data siswa, foto wajah, dan absensi tersimpan secara real-time di cloud.

Akun guru/dosen

Pengelola dapat membuat akun login baru untuk staf absensi.

Penyimpanan

Data siswa dan absensi saat ini disimpan pada penyimpanan browser perangkat ini. Data tidak otomatis tersinkron ke perangkat lain.

Data biometrik

Template wajah disimpan sebagai angka deskriptor, bukan foto. Persetujuan diperlukan sebelum mengumpulkan dan menyinkronkan data biometrik siswa. Sediakan metode absensi alternatif sesuai kebijakan sekolah.

Waktu masuk

Siswa yang melakukan absensi setelah pukul 07.00 akan diberi status terlambat. Waktu perangkat lokal digunakan untuk menentukan tanggal dan waktu.
